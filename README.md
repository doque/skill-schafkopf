# skill-schafkopf

Agent skill for Schafkopf, the Bavarian card game: rules, terminology, scoring and basic strategy, following the official rules of the [Schafkopfschule e.V.](https://schafkopfschule.de/regeln.html) (Schafkopfregeln 2024, Turnierregeln 2020).

## Install

```
npx skills add doque/skill-schafkopf
```

The skill lives in [`skills/schafkopf/SKILL.md`](skills/schafkopf/SKILL.md).
